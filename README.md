## Steps to make a repository locally

- make a folder
- open git bash and type git init to initialize a repository locally
- type touch README.md to make a file called "README.md" for github
- git add README.md
- git commit -m "Added README.md file"
- type git branch -M main
- go to github and make a new repository and don't add README.md file
- take the https or SSH key link to the repository depending on if you want it secure or not
- git remote add origin [https link| SSH key link](https://github.com/mohammed1215/ieee-task.git)
- git push origin main
